# Security Policy

## Supported versions

We support the latest released version of the module. Please upgrade before reporting an issue that may already be fixed.

## Reporting a vulnerability

**Do not** open a public GitHub issue for a security vulnerability.

Email **security@pathlyhq.com** with:

- a description of the issue and its impact;
- the steps to reproduce, or a proof of concept;
- the versions of the module, of PrestaShop and of PHP.

We aim to acknowledge reports within a few business days.
